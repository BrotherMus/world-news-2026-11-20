The world's news of Friday 20 November 2026 on one front page: 32 stories across six regions and fields from war to health and cricket, led by Russia's missile strike on Kyiv's bridges, Cyclone Akvan's landfall in Odisha and the AI sell-off that pushed the S&P 500 into a correction. It has a UTC timeline, key numbers, a numbered locator map and a date check naming the Thursday stories it left out.

`tools/render.mjs` draws the page as HTML with inline SVG and screenshots it with headless Edge to `entry.png`; `main.ts` copies that image to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
