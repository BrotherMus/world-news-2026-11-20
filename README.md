The world's news of Friday 20 November 2026 on one front page: 27 stories across six regions, led by the AI sell-off that pushed the S&P 500 into a correction, the EU–UK reset deal, Russia's barrage on Ukraine and the missile in a Polish field, a tanker on fire in the Strait of Hormuz, Saudi strikes in Yemen and COP31 running into overtime.

`tools/render.mjs` draws the page as HTML with inline SVG and screenshots it with headless Edge to `entry.png`; `main.ts` copies that image to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
